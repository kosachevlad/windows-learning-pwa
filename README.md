# Windows Learning PWA

Окрема PWA-версія навчального desktop-застосунку. Вона переносить ключові сценарії Android MVP у браузер: робочий стіл, Мої файли, Блокнот, Paint, Кошик, контекстні меню та локальне збереження.

PWA не потребує ADB або встановлення Android APK. Для керованого Chromebook достатньо відкрити сайт у Chrome, а за дозволу політик ChromeOS - встановити його як PWA.

## Поточний етап

- Vanilla HTML/CSS/JS без зовнішніх залежностей.
- Локальна файлова модель у `localStorage`.
- Вміст Блокнота і Paint зберігається разом із метаданими.
- Offline-ready через `manifest.webmanifest` і `service-worker.js`.
- Автотести домену файлових операцій через `node --test`.

## Запуск локально

```powershell
npm test
npm start
```

Після запуску відкрийте адресу, яку покаже `npm start`:

```text
http://127.0.0.1:4173
```

## Тестування по етапах

### Етап 1: репозиторій і домен

```powershell
npm test
```

Очікувано: тести створення файлів, перейменування, копіювання, Кошика і відновлення проходять.

### Етап 2: PWA-shell

```powershell
npm start
```

Перевірте в браузері: є робочий стіл, системні іконки, панель задач, контекстне меню правою кнопкою на тлі.

### Етап 3: сценарії файлів

```powershell
npm start
```

Правою кнопкою на робочому столі створіть папку, текстовий документ і рисунок. Подвійний клік відкриває відповідний застосунок, перейменування і видалення працюють через контекстне меню.

### Етап 4: локальне збереження

```powershell
npm start
```

Створіть файл, перезавантажте сторінку, перевірте що файл лишився. Для чистого старту натисніть "Скинути навчальне сховище" у меню Пуск.

### Етап 5: Chromebook без ADB

Опублікуйте каталог як статичний сайт на HTTPS або відкрийте його через шкільну систему розгортання. На Chromebook:

1. Відкрити URL у Chrome.
2. Переконатися, що сторінка працює без Android/ADB.
3. Відкрити DevTools або `chrome://serviceworker-internals`, якщо політики це дозволяють, і перевірити service worker.
4. У Chrome menu вибрати Install, якщо адміністратор дозволив PWA-install.

## Відношення до Android MVP

Android-проєкт `windows-learning-desktop-mvp` не змінювався. Поточний PWA-репозиторій переносить поведінкову модель, але не залежить від Kotlin/Room/Compose.
